# Implementation Plans

Future implementation plans for this project live in this directory.

Each plan file follows the `superpowers:writing-plans` skill format — a short spec (problem, proposed change, acceptance criteria, verification steps) written **before** any code is touched, one file per feature or refactor.

Naming: `NNN-short-slug.md` (e.g. `001-unify-pagination-dtos.md`). Keep plans small and independently reviewable.
